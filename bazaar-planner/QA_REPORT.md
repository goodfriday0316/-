# 개인 파일 가져오기 QA

검증일: 2026-10-27. 브라우저 Chromium154, 데스크톱1440×1100, 모바일390×844. 모든 게임 형태 입력은 직접 작성한 합성 데이터입니다. 실제 원본 JSON·게임 이미지는 취득하거나 프로젝트에 넣지 않았습니다.

## 새 브라우저 시나리오

1. 파일 선택 → Web Worker 변환 → 적용 전 결과 확인 → 개인 도감 적용. 합성8레코드 중3개 변환·4개 제외·1개 격리 확인.
2. 가져오기 과정의 요청을 감시하여 파일 이름·내용 표식이 URL/본문으로 전송되지 않고, 정적 코드 GET 요청만 발생함을 확인.
3. 원본 JSON의 원격 이미지 URL을 사용하지 않음. CSP `connect-src 'none'`으로 강제 외부 POST도 차단됨.
4. 브론즈 값을 이어받는 실버 속성, 명시적 골드0, 원시 미해석 효과, 활성 불확실 표시.
5. IndexedDB 복원·덱 저장·새로고침·복제/비교·JSON 내보내기/가져오기. 도감 삭제 후에도 덱 아이템 사본 유지.
6. 잘못된 JSON·모두 격리된 파일로 기존 개인 도감을 덮어쓰지 않음.
7. IndexedDB 미지원 상태의 탭 한정 사용·삭제 및 저장 실패 안내.
8. 손상된 저장 보고서로 관리 창이 중단되지 않음.
9. 모바일 터치 추가·이동·새로고침과 화면 가로 넘침 없음.

모바일은 Chromium 터치 모드이며 물리 기기·iOS Safari 검증은 수행하지 않았습니다.

## 발견·수정한 문제

- 수치 나눗셈이 Infinity가 되면 완성된 효과 대신 미해석 처리.
- 과도한 경고와 원본 키 길이 제한·격리 및 보고서 잘림 표시.
- 상속 도중 선언된 등급 자체가 빠지면 이후 속성을 추측하지 않고 격리.
- 단일·복수 영웅 필드가 잘못되거나 충돌하면 격리.
- 저장 불가 시 메모리 도감도 지울 수 있도록 분리.
- IndexedDB의 손상된 변환 보고서를 렌더링 전에 거부.
- 긴 카탈로그 해시로 생긴 모바일 가로 넘침 및 패치 null 표시 수정.

## 검증의 한계

원본 게임의 전체 Action 클래스·상속/삭제 규칙을 검증하지 않았습니다. 명시적 표시값이 없는 실제 능력 자리표시자는 미해석으로 남을 수 있습니다. 원본 게임의 현재 활성 풀과 최신 패치는 확인하지 않습니다. 실제 데이터 정확성·사용 권한 검증을 합성 테스트가 대신하지 않습니다.

실행 명령과 지원 범위: [LOCAL_FILE_IMPORT.md](docs/LOCAL_FILE_IMPORT.md). Cloudflare 배포는 수행하지 않았습니다.
