## 원본 프로젝트 확인

`src/main.tsx`, `src/model.ts`, CSS, TypeScript/Vite 설정, `package.json`, 잠금 파일, 테스트가 남아 있습니다. 이전 작업의 React·TypeScript·Vite 원본을 기반으로 수정했으며 압축된 JS/CSS를 수정하지 않았습니다. 운영 주소의 HTML에서 The Bazaar · Deck Atelier와 Vite 정적 자산 경로를 확인했습니다. 운영 자산 요청은 접근 제한이 있어 배포 번들과 작업 폴더 소스의 바이트 일치까지 검증하지는 못했습니다.

## 구현 완료

- UI와 분리된 `src/data/items.json` 카탈로그 및 출처·패치·번역 상태·등급별 원문 효과/수치·이미지 스키마.
- 허가된 공급자 전체 JSON을 일괄 처리하는 `scripts/update-items.mjs`. 원본 ID 네임스페이스, 중복 제거, 충돌/형식/패치 검증, 입력 해시, 버전 이력, 실패 시 이전 결과 복원.
- 데이터와 이미지 허가 분리. 승인 근거가 없으면 요청 전 중지. 허가 호스트의 안전한 래스터 이미지 다운로드 및 누락·미번역 보고서 생성.
- 공급자 원문 영어 유지. 공식 한국어의 출처 근거가 없으면 `untranslated` 표시.
- 영웅·이름(한국어/영어)·크기·태그 필터, 지원 등급별 효과/수치 미리보기, 이미지 오류 시 기존 벡터 아이콘 대체.
- 기존 ID/localStorage 키 유지, 마이그레이션 전 원본 백업, 배치별 아이템 사본 보존. 삭제·크기 변경된 아이템도 옛 덱의 배치를 보존. 샘플을 실제 아이템에 임의 매핑하지 않음.
- 다중 덱 생성·복제·비교·JSON 왕복·드래그·터치·10칸 검증 유지.
- 기본 이미지 드래그를 비활성화하고 드롭 애니메이션이 다음 입력을 가리는 문제 수정.
- 현재 Worker 이름 `b-boardmaker-mk1`용 정적 배포 설정과 기존 주소 유지 안내.

## 미완료 및 다음 단계

실제 데이터 획득, 실제 이미지 재배포, 공식 한국어 적용, 최신 패치 데이터 일치 검증은 미완료입니다. 현재 새 도감에는 아이템이 없어 실제 게임 덱을 새로 구성할 수 없습니다. 이전 덱은 보존해 볼 수 있습니다.

남은 입력은 운영자/권리자의 허가 근거와 허용된 일괄 JSON/API입니다. 확보되면 전체 공급자 파일을 자동 변환합니다. 공급자 스키마가 정규 계약과 다르면 공급자별 일괄 변환 어댑터가 추가로 필요합니다. 승인 매니페스트 값만 임의로 바꾸어 실행해서는 안 됩니다. 파이프라인이 URL의 법적 효력을 스스로 판정하는 것은 아닙니다.
