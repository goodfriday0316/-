# 보드 세로 넘침 / 이미지 없는 항목 숨김

## 변경
- 보드 grid 행을 `minmax(0, 1fr)`로 제한하고 배치 wrapper와 카드의 min/max 높이를 보드에 맞췄습니다.
- 카드의 이미지 영역은 고정 90px 대신 남는 세로 공간을 사용합니다. 텍스트는 한 줄로 제한하고 긴 이름/태그는 말줄임 처리합니다. 전체 이름은 기존 상세 화면에서 확인할 수 있습니다.
- 실제 이미지에 `object-fit: contain`을 적용해 원본 비율을 유지하고 자르지 않습니다.
- 카드 바깥을 가려 문제를 숨기는 대신 grid/flex 높이 계산을 수정했습니다.
- Chronicle 도감은 현재 브라우저 IndexedDB에 이미지가 저장된 항목을 기본으로 표시합니다. ZIP을 아직 가져오지 않았다면 도감이 비어 있을 수 있으므로 ZIP 가져오기 안내를 표시합니다.
- '이미지 없는 아이템 표시'를 켜면 전체 메타데이터를 다시 볼 수 있습니다. 전역 표시 개수와 영웅별 개수를 별도로 표시합니다.
- 이 옵션은 기본값 꺼짐이며 새로고침 시 기본값으로 돌아갑니다. 기존 raw 형식/번들 도감은 기존 호환 동작을 유지합니다.
- 필터는 도감 목록에만 적용하며 원본 데이터, 기존 덱과 저장된 아이템 사본을 수정·삭제하지 않습니다.
- 이미지 유무와 게임 활성 여부는 별개로 안내합니다.

## 검증
- 기존 보드·드래그·덱·모바일 회귀 13개 통과.
- 프로덕션/로컬 가져오기/이미지 저장/Worker 대체 경로 테스트 17개 통과.
- 실제 개인 DB와 실제 이미지 1,080장이 저장된 복사 프로필로 PC(1440×1100), 모바일(390×844) 통합 테스트 각각 통과.
- 영웅 필터를 순회해 고유 아이템 ID로 집계: 기본 1,080개 / 옵션 켬 1,117개 / 숨겨지는 항목 37개.
- 실제 1칸·2칸·3칸 아이템 모두 카드 전체와 이름이 보드 내부에 들어옴. PC 카드 높이 182px, 모바일 165px. 내부 scrollHeight가 clientHeight를 넘지 않음.
- 마우스 및 CDP 터치 긴 누르기로 실제 대형 아이템을 이동하고 새로고침 후 위치·이미지 유지 확인.
- 이미지 없는 실제 아이템을 보드에 배치한 뒤 필터를 꺼도 그대로 유지됨.
- 실제 아이템과 이미지 없는 아이템을 함께 담은 덱의 내보내기 Blob 내용과 JSON 파일 가져오기/새로고침 복원을 검증. 일반 회귀에서는 실제 파일 다운로드도 검증.
- 복사된 persistent Chromium 프로필이 OS 다운로드 단계에서 종료되는 러너 문제가 있어 실제 데이터 통합 테스트는 OS 전달 직전의 내보내기 Blob을 캡처합니다. 앱의 내보내기 구현은 변경하지 않았습니다.

## 테스트 재현
기본: `npm test -- --workers=2`, `npm run test:production`.
실제 파일 통합 테스트는 개인 자료를 저장소에 넣지 않고 다음 변수를 지정해 실행합니다:

```sh
BAZAAR_PRIVATE_PROFILE=/path/to/test-profile CHRONICLE_TEST_JSON=/path/to/chronicle-local.json npx playwright test --config playwright.production.config.ts tests/real-ui.spec.ts --workers=1
```

테스트용 브라우저 프로필에는 동일한 localhost:5175에서 로컬 도감과 1,080개 이미지를 이미 가져와야 합니다. 실제 개인 계정용 브라우저 프로필 대신 별도 테스트 프로필을 사용하세요. 테스트는 프로필을 임시 폴더로 복사해 사용합니다.

## 배포
`downloads/bazaar-cloudflare-pages.zip`을 기존 Cloudflare Pages 프로젝트의 새 배포로 적용합니다. 게임 데이터·변환 JSON·실제 이미지·테스트 프로필은 ZIP에 포함하지 않습니다.
같은 도메인을 유지하면 기존 로컬 도감/이미지/덱을 그대로 사용할 수 있습니다. 사이트 데이터 삭제는 필요하지 않습니다. 배포 후 Ctrl+F5로 새로고침하세요.
직접 Cloudflare 배포는 수행하지 않았습니다.
