# 아이템 정보 간소화 결과

## 구현

카드와 간단 정보창에서 임시 등급, 등급 선택, 효과, UUID, 미해석 참조, Chronicle 경고와 번역·패치 검증 메시지를 제거했습니다. 이름(확인된 한국어 우선), 영어 보조 이름, 실제 이미지, 크기만 표시합니다.

확인 기록이 있는 Bazaardex URL은 카드 클릭 시 새 탭으로 엽니다. 미연결 카드는 간단 정보창을 열며 외부 링크 버튼은 비활성화합니다. 별도 추가·제거 버튼을 두고 클릭과 드래그 충돌을 방지합니다.

기존 tier/enchant/effects/source/local 데이터는 내부·저장 JSON에 보존합니다. 덱 스키마, template_id와 이미지 저장소는 변경하지 않습니다. 비교 화면에서도 등급은 숨깁니다.

'한국어 이름·외부 링크' 관리에서 개인 매핑 JSON을 불러옵니다. UUID와 영어 이름을 정확히 비교하며 이름 유사도나 임의 URL 생성은 사용하지 않습니다. 공식 한국어 파일의 출처 기록과 직접 확인한 상세 페이지 기록이 필요합니다. 별도 IndexedDB에 저장해 표시·검색만 보완하며 원본과 기존 덱 사본은 바꾸지 않습니다. 앱이 사용자 기록의 공식성이나 현재 외부 페이지 내용을 독립적으로 인증하는 것은 아닙니다.

## 실제 확보 수치

| 구분 | 실제 확인·매칭 | 미확인·미검증 |
| --- | ---: | ---: |
| 공식 한국어 이름 | 0 | 1,117 |
| Bazaardex 개별 상세 URL | 0 | 1,117 |

현재 제공된 Chronicle DB와 WebP에는 한국어 문자열이나 상세 URL이 없습니다. 미확인은 잘못된 매칭이 발생했다는 뜻이 아니며, 해당 항목은 영어와 링크 비활성 상태를 유지합니다.

한국어는 GameData.db(.zip)의 template_id → Localization.Title.Key → 공식 ko-KR.bytes의 translation.hash를 정확히 결합하는 로컬 추출 도구를 구현했습니다. 실제 두 파일은 아직 없어 공식 문자열 매칭은 미검증입니다. [실제 파일 경로·이용 조건 확인의 한계·로컬 변환 방법](LOCALIZATION_RESEARCH.md)을 참조하세요.

Bazaardex는 이 환경의 프록시 CONNECT 단계에서 403으로 차단되어 실제 개별 페이지 경로와 이름을 확인할 수 없었습니다. 사이트 서버의 장애로 단정하지 않습니다. 확인되지 않은 slug를 만들지 않습니다. [개인 매핑 파일 형식](LOCAL_ITEM_DETAILS.md)을 참조하세요.

## 검증

- 기본 PC/모바일·마우스·터치·키보드·덱 회귀 14개 통과.
- 프로덕션·매핑·한영 검색·이미지·실제 PC/모바일 통합 21개 통과.
- 매핑 파서·원본 보존·URL·오매칭 거부 단위 테스트 5개 통과.
- 로컬 한국어 추출의 정확한 키·중복·읽기 전용·이름 충돌·ZIP 검사 5개 통과.
- 실제 이미지 1,080개 저장 프로필에서 1/2/3칸 배치, 이미지 표시, 드래그, 필터, JSON 복원을 검증했습니다.
- 기존 골드/다이아몬드·마법부여 값이 화면에서 숨겨져도 JSON 백업·복원·새로고침 후 보존되는지 확인했습니다.
- 합성 매핑 테스트 성공을 실제 공식 번역·Bazaardex 페이지 확보로 간주하지 않습니다.

## 배포와 남은 자료

`downloads/bazaar-cloudflare-pages.zip`은 앱만 포함합니다. 게임 DB·공식 문자열·이미지·실제 매핑은 포함하지 않습니다. 기존 Cloudflare 프로젝트에 새 배포로 적용한 뒤 Ctrl+F5로 새로고침하세요. 같은 도메인에서 기존 로컬 데이터와 덱을 유지할 수 있으며 사이트 데이터 삭제는 필요하지 않습니다.

Cloudflare에 직접 배포하지 않았습니다. 실제 한국어 적용에는 PC의 GameData.db.zip(또는 GameData.db), translations/ko-KR.bytes로 로컬 추출을 실행해야 합니다. 실제 Bazaardex 링크 적용에는 개별 페이지 접근 및 정확한 ID/이름 확인 기록이 추가로 필요합니다.
