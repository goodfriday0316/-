# 개인 한국어 이름·Bazaardex 매핑

한국어 명칭과 외부 상세 URL은 게임 메타데이터/이미지와 별도의 개인 매핑으로 관리합니다. `한국어 이름·외부 링크` 관리 창에서 JSON을 선택하고 결과를 확인한 뒤 적용합니다. IndexedDB `bazaar-item-details-v1`에 저장하며 파일을 서버로 보내지 않습니다. 덱 데이터·등급·이미지 저장소는 변경하지 않습니다.

## 파일 형식

최상위는 `{"format":"bazaar-item-details-v1","records":[...]}`입니다. `records`는 최대 20,000개이며 파일은 5MB 이하입니다. 각 레코드는 다음 필드를 사용합니다.

| 필드 | 조건 |
| --- | --- |
| `templateId` | 도감 `source.id`와 정확히 같은 표준 소문자 UUID |
| `nameEn` | 해당 UUID 아이템의 영어 이름과 대소문자까지 정확히 일치 |
| `nameKo` | 선택 사항. 공식 한국어 원본에서 확인한 이름. 임의 번역 금지 |
| `koreanProvenance` | `nameKo`가 있으면 필수. 아래 출처 필드 사용 |
| `bazaardex` | 선택 사항. 아래 직접 확인한 상세 페이지 기록 |

`koreanProvenance`는 `kind: "official-game-localization"`, `source`(원본 파일명), `key`(공식 문자열의 연결 키), `sourceSHA256`(원본 파일의 소문자 SHA-256 64자리)를 포함합니다. 실제 게임 원본이 없는 상태에서 이름을 기계번역하고 이 값을 붙이면 공식 명칭의 증거가 되지 않습니다. 앱은 기록의 형식을 확인하며 원본 파일을 갖고 있지 않아 공식 출처 자체를 독립적으로 인증하지는 않습니다.

`bazaardex`는 `url`, `sourcePage`, `verifiedNameEn`, `verifiedAt`을 포함합니다. `sourcePage`는 직접 확인한 개별 아이템 페이지 URL로 `url`과 동일해야 하고, `verifiedNameEn`은 도감 영어 이름과 정확히 일치해야 합니다. `verifiedAt`은 확인 시각의 ISO 형식입니다. URL은 HTTPS의 `www.bazaardex.com` 또는 `bazaardex.com` 호스트만 허용하며 루트·검색·로그인·API·약관 등의 경로와 query/hash, 사용자 정보, 포트는 허용하지 않습니다. 사이트의 실제 개별 페이지 경로를 확인하지 않은 상태에서 임의 slug를 만들지 않습니다.

이름·링크는 사용자 제공 확인 기록입니다. 브라우저 앱이 외부 사이트를 검색하거나 페이지 내용을 온라인으로 재검증하지 않습니다. 별도 검증 기록이 없는 링크는 비활성화합니다.

## 정확한 매칭과 호환

- ID와 영어 이름을 모두 확인합니다. 이름 유사도나 번역 문자열로 연결하지 않습니다.
- 같은 ID가 여러 번 있으면 모두 제외합니다. 알 수 없는 ID, 달라진 영어 이름, 잘못된 출처는 결과에 표시합니다.
- 한국어 이름 또는 링크 중 하나 이상이 있어야 적용 가능합니다. 유효한 레코드만 저장합니다.
- 같은 ID라도 기존 덱 사본의 영어 이름이 다르면 매핑을 적용하지 않습니다.
- 적용 시 화면 표시와 검색만 보완합니다. 원본 이름, itemId, 이미지 연결, 기존 덱 사본과 등급 값은 바꾸지 않습니다.
- 관리 창에서 매핑만 지우면 원래 표시로 돌아갑니다. 덱과 이미지는 유지합니다.
- 매핑 JSON은 Cloudflare의 public/src/data 폴더에 넣지 않습니다.

## 현재 확보 상태

제공된 Chronicle DB의 1,117개 항목에는 영어 이름만 있습니다. 현재 공식 한국어 원본 파일과 Bazaardex 개별 페이지 검증 자료가 제공되지 않아, 이 모듈이 자동 생성하는 공식 이름/상세 링크는 각각 0개입니다. 연구·로컬 추출 도구로 확보된 자료만 정확한 ID 기준으로 추가해야 합니다.
