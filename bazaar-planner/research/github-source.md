## lifein-ai/bazaar-helper

- 저장소: https://github.com/lifein-ai/bazaar-helper
- README: https://github.com/lifein-ai/bazaar-helper/blob/main/README.md
- 라이선스 메타데이터: https://api.github.com/repos/lifein-ai/bazaar-helper
- 라이선스 확인 경로: https://api.github.com/repos/lifein-ai/bazaar-helper/license

공개 GitHub 페이지에서 README와 파일 목록을 확인했다. 공개 열람 가능 여부는 코드·데이터·이미지를 복제하거나 재배포할 허락과 별개다. 검토된 파일 목록에는 LICENSE가 없고, 담당 에이전트의 GitHub 메타데이터 확인에서도 `license: null`이었다. 확인된 main 기준 최근 갱신은 8월 10일이며, 이것만으로 현재 게임 패치와 일치한다고 판단할 수 없다.

README의 데이터 설명은 `cards_generated.json`을 “从游戏 cache 导入的卡牌基础数据”(게임 캐시에서 가져온 카드 기본 데이터)라고 명시한다. 또한 `scripts/import_game_cache.py`를 공식 캐시에서 카드·스킬·조우 데이터를 가져오는 스크립트로 설명한다. 따라서 저장소 작성자가 작성한 코드에 향후 허용 라이선스가 추가되더라도 원작 게임 데이터와 이미지의 권한은 별도로 확인해야 한다.

README에서 확인된 관련 구조는 `data/`, `raw_data/`, `scripts/`, `src/`, `bepinex/BazaarStateExporter/`다. 이 프로젝트는 게임 상태를 읽어 로컬 추천 API와 게임 오버레이를 제공하는 도구로 설명되며, 덱 플래너용 공식 데이터 배포 서비스는 아니다.

**결론:** 현재 확인한 근거로 이 저장소의 코드·실제 카드 데이터·이미지를 본 앱에 자동 복제하거나 공개 배포하지 않는다. 저장소 소유자에게 코드 및 데이터의 재사용 허락과 데이터의 원출처·게임 권리자의 허가 범위를 확인해야 한다. 커밋 시각이나 공개 저장소라는 사실은 권한 증거가 아니다.

## The Bazaar Wiki 대안

- 검토 대상: https://thebazaar.wiki.gg/wiki/The_Bazaar_Wiki

현재 환경에서 위키 접근이 거부되어 해당 사이트의 실제 라이선스 고지, API 조건, robots 정책을 검증하지 못했다. 따라서 이 위키의 텍스트가 특정 CC 라이선스라고 확정하지 않았으며, 일괄 수집 가능한 공급원으로 승인하지 않았다. 위키 텍스트에 재사용 라이선스가 확인되더라도 게임 원본 이미지의 권한은 별도일 수 있다. API 공개와 robots 허용도 저작물 재배포 허락을 대신하지 않는다.

## 사용 가능한 자동화 경로

현재는 재사용 권한과 최신 패치를 함께 검증한 실제 데이터 공급원이 없다. 앱은 권한이 확인된 버전별 JSON 공급원을 받도록 준비하되 검증 전에는 실제 데이터를 비워 두는 것이 적절하다.

권한 확인 후 공급원별 URL·라이선스·저작자·귀속 문구·패치 버전·취득 시각·원본 해시를 기록하고, 스키마 검사 및 아이템 ID 검사를 통과한 JSON만 배포한다. 이미지는 파일별 재배포 허용 근거가 있을 때만 포함하고, 근거가 없으면 자체 플레이스홀더를 유지한다. 데이터 업데이트는 변경 검토 가능한 PR을 생성하는 방식으로 운영하면 패치 변경과 권한 기록을 함께 보존할 수 있다.
